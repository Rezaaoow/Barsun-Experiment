# LifeTrade Online — بستهٔ MVP استقرار

این بسته نسخهٔ اولیهٔ آنلاین با رابط فعلی آزمایش، پاسخ لمسی/صفحه‌کلید، شناسهٔ تصادفی، ثبت مرحله‌ای پاسخ‌ها، شناسهٔ یکتای جلوگیری از ثبت تکراری و API خروجی CSV محافظت‌شده است.

## مهم
این نسخه هنوز برای نمونه‌گیری اصلی تأیید نشده است. ابتدا منطق آزمایش، نمایش محرک‌ها روی موبایل، رفتار در قطع اینترنت، RT و خروجی CSV باید در پایلوت بررسی شوند. `render.yaml` نمونهٔ استقرار Render است؛ برای دادهٔ پایدار PostgreSQL لازم است و پلن/متغیرهای محیطی باید هنگام استقرار تأیید شوند.

## اجرای محلی
1. Python 3.11+ نصب کنید.
2. `pip install -r requirements.txt`
3. یک توکن مدیریتی تنظیم کنید: `export ADMIN_TOKEN='یک-رمز-طولانی'`
4. `uvicorn main:app --reload`
5. مرورگر: `http://127.0.0.1:8000`
6. سلامت API: `http://127.0.0.1:8000/api/health`

بدون `DATABASE_URL` از SQLite محلی استفاده می‌شود. در production از PostgreSQL استفاده کنید؛ دیسک محلی بسیاری از هاست‌های موقت پایدار نیست.

## استخراج داده
در درخواست `GET /api/admin/export.csv` هدر `X-Admin-Token` با مقدار `ADMIN_TOKEN` ارسال شود. این توکن را در کد مرورگر قرار ندهید. فهرست جلسات در `/api/admin/sessions` است.

## سیاست الگوریتم مرزی
ردیف داخلی صفرمبنا با clamp در بازهٔ ۰ تا ۳۰ محدود می‌شود. `requested_row`، `displayed_row`، `requested_next_row`، `bounded_next_row` و `boundary_hit` برای هر پاسخ ثبت می‌شوند.

## محدودیت RT
RT با `performance.now()` از زمان بلافاصله پس از ساخت عناصر محرک اندازه‌گیری می‌شود؛ این معادل دقیق همگام‌سازی فریم PsychoPy نیست. دستگاه، مرورگر، نرخ تازه‌سازی و لمس می‌توانند روی RT اثر بگذارند. این تفاوت باید در گزارش پژوهشی ذکر شود و پایلوت انجام شود.

## امنیت و حریم خصوصی
شناسهٔ تصادفی به‌تنهایی ناشناس‌بودن مطلق را تضمین نمی‌کند. متادیتای دستگاه فعلاً شامل user-agent و اندازهٔ صفحه است؛ اگر به آن نیاز ندارید، حذفش کنید. دسترسی خروجی CSV باید محدود بماند و `ADMIN_TOKEN` محرمانه باشد.
